# 悦音音乐

一款支持 QQ 音乐、网易云与酷狗音乐接入的播放器，提供账号收藏、多音源管理和灵活的播放设置。

当前独立入口版本：**0.4.0**。Android 继续按架构分包；Windows x64 的构建与验证状态见[验收记录](docs/交付文档/悦音音乐040验收记录.md)。

## 功能

- **账号与收藏**：QQ、网易云及酷狗入口；酷狗增加歌单浏览，分页失败保留已获取内容并明确提示未完整。
- **自定义音源**：通过 HTTPS 链接导入兼容的洛雪音源脚本。
- **多音源管理**：保存多个音源，支持更新、排序、设为首选、启停和删除。
- **列表检查**：名称和平台筛选、紧凑列表、固定保存按钮、完整筛选结果逐项检查与取消；失败保留草稿。
- **自动切换**：启用后，取流或播放失败时自动尝试其他可用音源。
- **音质优先**：优先尝试最高可用音质，并显示降档与来源信息。
- **播放详情**：查看尝试记录、失败原因和未试音源，达到单轮等待上限后可继续尝试。

## 安装

当前提供 Android APK，按设备架构选择：

| 架构 | 适用设备 |
| --- | --- |
| arm64-v8a | 大多数安卓手机 |
| armeabi-v7a | 支持的旧款 32 位设备 |
| x86_64 | x86_64 安卓模拟器或设备 |

Windows 使用独立品牌、宽屏布局和受限 WebView2 音源宿主，完整包包含 EXE、DLL、data 与运行时许可，详见[Windows 说明](docs/交付文档/悦音音乐040Windows说明.md)。iOS 本轮没有构建或交付安装包。

## 使用音源

1. 打开“我的 → 自定义音源 → 多音源管理”。
2. 粘贴具体的 HTTPS 脚本链接，点击“从链接导入”。
3. 启用需要的音源，设置首选和尝试顺序。新导入的音源默认关闭。
4. 点击“使用推荐设置”，开启音源优先、失败自动切换和最高可用音质。
5. 点击“保存设置”后开始播放，也可按自己的偏好调整这些选项。

最高可用模式会先尝试各音源的高音质，再逐档降低。实际可用音质取决于歌曲和音源返回的资源；请求档位与音频实际音质分别显示。

新版列表将低频操作放进每条音源的“更多”菜单。返回时可保存、放弃或继续编辑；筛选仅改变显示，不修改实际播放顺序。旧版操作背景见[使用说明](docs/交付文档/悦音音乐033使用说明.md)。

## 兼容范围与问题反馈

音源导入成功不等于每首歌曲都能播放。固定版本的全部20个入口已完整诊断：移动协议主机初始化由9个提升到18个，其中17个声明悦音支持的平台；Windows真实宿主初始化17个，其中16个声明支持的平台。平台范围、各源失败及完整SHA-256见[20源兼容矩阵](docs/交付文档/悦音音乐040音源兼容矩阵.md)。Android 本轮没有连接设备，真实账号、完整歌曲播放与音质仍按[验收记录](docs/交付文档/悦音音乐040验收记录.md)列为未测。

反馈问题时，请提供应用版本、设备系统、音源名称及版本、歌曲与歌手、操作步骤和页面错误提示。请勿附带账号 Cookie、访问令牌或签名口令。

## 开发

项目使用 Flutter，悦音音乐入口为 `lib/main_video.dart`，相关界面与兼容层位于 `lib/video_app/`。

环境配置、测试、自有签名及 APK 分包步骤见[开发与构建](docs/交付文档/悦音音乐开发与构建.md)。
