# IK Music 搜索平台标签与同步状态快改实施票据

## 用户已确认的场景与本轮范围

用户已看过快稿并要求继续，当前明确先做可看的快速候选，本轮不执行测试、静态分析、格式检查、成品构建或安装。主任务负责接线，本子任务只修改搜索正文、音乐库正文及新增中文文案文件。之前AX首红与最小修复保持不动。

搜索结果现在按“全部来源”堆叠，平台之间的结果、加载和错误混在长页面中；用户确认改为横向平台标签，一次查看一个平台。音乐库同步失败的整行常驻提示挤占内容，用户确认收为同步按钮附近的简短状态，按需展开真实原因。两项均为现有展示增强，复用现有控制器、数据与操作入口，不增加服务或外部系统。

## 实施选择

搜索方案一让每次切标签重新请求单个平台，会改变现有并行搜索及缓存行为；方案二保留所有分平台请求，只展示当前平台，采用方案二。新增 `IkSearchWorkspace.platformResultTabs = false`，旧缺省仍走原展示；开启后顺序为网易、QQ、酷狗、本地，首次优先QQ，随后在当前页面状态中保留上次所选。结果滚动按关键词和平台记录，关键词变化重置结果位置，当前平台的首次加载决定当前位置恢复，不等其它平台请求结束。空关键词保留原热词，不再复制推荐内容。

同步方案一把所有错误完全移到设置会让失败不可发现；方案二保留按钮旁的短状态，点击打开锚定的小面板，采用方案二。新增 `IkLibraryWorkspace.compactSyncStatus = false`，错误原因原文保留，重试仅按 `error.canRetry` 提供，账号失效或未登录提供原账号入口，正在同步时动作禁用。局部展示不清空任何收藏或同步缓存；本地收藏读取错误仍走原来的明显提示和重试，不被收起。

## 受影响调用方与接口

唯一产品装配在 `lib/video_app/video_app.dart` 的 `_VideoHome.build`，由主任务传入两个可选参数；本子任务不修改该文件。既有测试及其它直接构造方不传参数时保留原行为。所有公开方法、控制器签名和数据返回类型不变，不修改 `IkSearchController`、`VideoLibrary`、同步服务或账号服务。

## 待执行的验收门规格

本轮按用户指令不执行以下门，也不宣称已有红绿结果；正式验证需在用户恢复授权后补执行记录。

1. 搜索：非空关键词首次选QQ，切网易／酷狗／本地只显示对应结果；同关键词往返平台恢复各自位置；换关键词从顶部开始；当前平台返回后能浏览，即使另一平台仍在首次加载。
2. 搜索：空结果、首次失败、分页失败显示当前平台真实状态；可重试才有重试，可连接账号才有连接动作；分页继续追加且旧结果保留；空关键词恢复热词且不重复每日推荐。
3. 同步：收藏数据保留，错误仅在所属平台同步按钮旁出现；点击状态可读完整真实原因；网络错误按canRetry重试，失效账号有重连，禁止重试的错误不出现重试按钮；同步中按钮和面板动作禁用。
4. 同步：失效平台已从loggedIn移除时仍有可达的状态与账号入口；本地读失败仍可见且可重试；面板点击外部／Esc可关闭，不使用底部弹窗。
5. 兼容：两个新增参数缺省均为false时，原搜索来源选择器、分组列表、错误提示及滚动行为不变。
