# 本机LX音源受控迁移设计

## 背景与目标

用户已授权把本机LX保存的音源植入IK，避免重复手动导入。迁移范围仅为音源脚本、其名称／版本和当前选择，不读取账号、收藏、Cookie或其他凭据数据。私有脚本仅保留在用户本地预览交付物中，不进入产品资产或公开仓库。

本票据记录格式与导入契约；不包含脚本正文、私有地址或本机账号标识。此轮不运行音源脚本、不调用运行时inspect、不修改正在使用的Hive或LX配置，也不把静态格式检查当作音源可用性证明。

## 方案对比

方案A由外部工具直接改写正在运行的IK数据库。该方式绕过产品持久化、编辑状态和初始化边界，存在覆盖、锁冲突与假启用风险，不采用。

方案B导出私有伴随目录，由IK新增的本地迁移入口受控读取，串行初始化后通过既有设置持久化边界提交。目录外的产品流程保持原样，按内容哈希去重，失败项保留明确信息且不启用。采用方案B。

## 已确认的LX存储格式

从本机安装包的静态源码确认，LX 2.12.6使用独立音源JSON：顶层为`userApis`数组，条目包含`id/name/description/version/author/homepage/allowShowUpdateAlert/script`。脚本保存为`gz_`前缀，加上zlib deflate字节的Base64文本；不是gzip，也不是可直接执行的JavaScript。应使用zlib inflate解压为UTF-8脚本，严格解码并计算原始字节SHA-256。

当前选择来自配置中的`setting["common.apiSource"]`，只用于与音源条目的id作内存匹配；不把原id或完整配置复制到伴随目录。安装包只作静态读取，不执行安装包模块或用户脚本。

本次定位的8条音源均可解压并严格UTF-8解码，共479951字节；每条小于1MiB，8个内容哈希互不相同。存储中的名称／版本与脚本头一致。全部条目均没有储存原始导入地址，也没有明确的更新地址头；部分含动态更新代码，但不能据此推断可下载的脚本地址。

## 私有伴随目录与数据结构

交付目录内仅包含`manifest.json`和`scripts/`。正式预览程序集成时，将其作为可执行文件旁的`local-lx-sources/`目录。脚本使用内容哈希命名，避免文件名受音源展示名称影响。

```json
{
  "schemaVersion": 1,
  "preferSelected": true,
  "sourceFirstWhenSelected": true,
  "sources": [
    {
      "name": "音源展示名称",
      "version": "音源版本",
      "selected": false,
      "relativeFile": "scripts/<sha256>.js",
      "sha256": "<原始脚本字节SHA-256>",
      "byteLength": 1234
    }
  ]
}
```

`updateUrl`为可选字段，仅在来源中确有可信HTTPS脚本链接时才可写入；本次全部省略。主页、说明、接口地址以及动态更新对象均不得猜成更新地址。没有更新地址时，产品显示本地音源及重新导入说明，不发起虚构地址的网络请求。

## 产品接入约束

新增本地桥接入口，不修改既有导入方法签名。仅读取固定伴随目录及`manifest.json`声明的受限相对路径；拒绝绝对路径、父级路径、目录跳转或目录外文件。读取前检查条目数、声明大小和总大小，读取后逐项核对原字节SHA-256与严格UTF-8头部；不得把不匹配的脚本交给运行时。

产品启动后后台串行初始化。成功条目按规范脚本SHA-256与已有集合去重，经现有串行持久化接口合并，不覆盖旧音源、编辑草稿、下载授权或现有自动切源设置。失败逐项展示，不激活、不把不支持或需要激活的源标为可用。

只有本地清单中唯一`selected`条目初始化成功后，`preferSelected`才允许将其设为首选；`sourceFirstWhenSelected`才允许启用备用源优先。未选中的成功条目不能代替失败的选中项触发这些策略，`autoSwitch`始终保留现值。

已导入内容用持久化内容标记或现有集合哈希防止每次启动反复导入；用户后来停用或移除的内容不能因目录仍在而静默恢复。失败条目可通过明确重试动作重新准备，不在后台无限重试。原始本地来源身份与可选更新地址应分开保存，不能伪装成公开仓库音源。

## 场景与待执行验收门

| 场景 | 用户可见结果 | 功能约束 |
| --- | --- | --- |
| 首次读取完整私有目录 | 列出所有声明音源及逐项准备状态 | 完整读取8条，不截断；长度和hash逐项匹配 |
| 多条内容已存在 | 保留原配置，显示已有或跳过重复 | 按脚本hash去重，不重新生成重复条目 |
| 选中源准备成功 | 该源成为首选并启用指定的源优先 | 仅清单明确标记时更改，autoSwitch与下载授权不变 |
| 选中源不兼容／需要激活／超时 | 显示真实失败，原播放来源继续可用 | 不假造平台能力、不启用失败源、不改首选 |
| 文件被替换或路径越界 | 明确迁移失败 | 校验前不初始化，目录外内容不读取 |
| 用户正在编辑或后台设置已变化 | 暂缓迁移提交 | 在串行持久化边界内重新核对状态后合并 |
| 已导入后重启、停用或删除 | 不重复导入或静默恢复 | 成功标记与用户选择继续生效 |
| 缺少原更新地址 | 显示本地导入与重新导入提示 | 不猜链接，不把主页或接口当脚本更新源 |

## 实施、保留与回滚

先形成本票据与清单契约，再导出本机私有脚本及清单，由主任务实现新增本地桥接和装配。私有目录属于用户授权的正式本地迁移交付物，长期保留；公开仓库仅保留通用实现与本票据，不包含脚本或私有URL。

回滚时关闭或撤销新桥接装配，旧播放和导入路径继续工作。已导入音源可通过产品既有管理入口停用或删除；外部工具不直接改Hive，也不批量清理用户原有文件。

本轮仅完成只读定位、格式确认和正式私有导出，不运行上述产品验收门。

## 新增产品桥接接口与实现约束

新增`lib/video_app/built_in/local_lx_source_bridge.dart`，主装配与界面由主任务接入，既有公开接口不变。

```dart
class IkLocalLxSourceBridge extends ChangeNotifier {
  IkLocalLxSourceBridge({
    required IkManagedSourceSettings settings,
    required LxSourceEngine engine,
    required Directory directory,
    required String runtimeId,
    bool Function()? isSourceWorkBusy,
  });
  Future<void> importOnce();
  Future<void> retryFailures();
  bool get busy;
  String? get message;
  List<IkLocalLxSourceResult> get results;
}
```

结果条目公开名称、版本、hash、状态码和中文状态。主任务可通过`isSourceWorkBusy`提供目录准备／更新占用状态；默认不额外阻断。每项初始化前和串行提交内均检查编辑、更新及写入阻断，不进行长时间忙等；暂停项留待明确重试。唯一选中项优先准备，但结果仍完整呈现清单全部条目。

用户在编辑页面点击`retryFailures`时，只安排本实例内的重试，不绕过编辑保护。界面显示“已安排重试，保存音源草稿并离开音源设置后自动导入”；2秒定时观察占用状态，空闲时只启动一次，最多等待2分钟，超时提示再次重试。没有未保存修改时离开即可；未保存草稿仍持有编辑保护。等待期busy为false，`retryQueued`为true；dispose取消定时器，不修改或放弃用户草稿。

清单最多64项且正文最多128KiB，超出整体拒绝，不静默截断。脚本单项1MiB、清单声明合计8MiB，严格匹配`scripts/<sha256>.js`；实际长度、原字节hash和头部信息逐项核对。拒绝符号链接／目录外的真实路径。初始化使用既有engine.inspect，单项5秒取消预算；已有相同脚本hash且当前运行时检查记录为initialized时复用，不重复执行初始化。

新增独立迁移收据键，成功hash后续启动不会再导入，用户移除或停用不会复活；失败记录保留错误分类和安全中文状态，普通启动不自动反复初始化，仅明确重试失败／暂停项。受管设置成功持久化后，再一并写入迁移收据与`SourceCheckStore`初始化记录；中途失败可凭当前集合hash幂等恢复。导入不更新受管目录身份，不冒充仓库源。

新源id为`local-lx:<规范脚本sha256>`，origin为本机脚本文件URI，启用状态为true、下载授权为false；旧集合中的相同hash保留其原启用、顺序、下载授权和身份。提交在settings.serialize内基于最新集合合并，settings.persist使用manual:false。选中项的首选／源优先仅在首次成功、没有编辑或用户策略变更、HTTP自定义源未启用时应用；否则保留当前策略并记录该决定，后续重试不抢回首选。autoSwitch始终保持。

此阶段仅编写产品实现，不在开发会话执行本地脚本或产品验收；脚本只由用户随后启动的产品初始化。

桥接源码已落盘并完成人工收口，未执行测试、analyze、format、构建或脚本。当前选中源若与已有列表条目内容相同，复用当前运行时已初始化记录；首次策略满足条件时仍可设为首选，状态显示“已在列表中（已有名称）”，不重命名或创建重复音源。
