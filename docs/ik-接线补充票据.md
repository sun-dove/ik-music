# ik 接线补充票据

本票据属于用户已确认的完整改版。调用关系复核发现复用页面有少量独立产品契约未传入的问题，必须随本版修复。

## 下载音质

专辑整张缓存、榜单整榜缓存、歌单批量下载与下载按钮长按缓存原本固定标准音质；通用歌曲菜单自行选择会员音质。独立入口应使用“我的”保存的下载音质。新增可空 downloadQualityProvider；只有 main_video 覆盖，五处消费点缺省继续原策略。下载按钮显式选择某首歌曲档位仍作为用户主动覆盖。回滚：移除独立覆盖，原入口全部继续缺省。

正式门 ik_download_quality_test 已在缺适配模块时真实失败；实施后检查默认标准音质与独立 lossless 两路，歌曲菜单必须返回实际提交档位。

## 移动端统一音质和外观

新“我的”使用共同设置页，原装配在非 Windows 只改 QQ 音质，且显示无回调的背景字体项。独立入口复用已经验收的统一偏好读取器（不增加旧键修改），把同一实例传给播放器路由、设置与下载；移动端没有桌面外观能力时不展示不可操作的桌面条目。旧构造新增参数均可空，旧默认路径保持。回滚：移除独立配置注入及可选显示参数。

## 账号变化

首页打开的独立登录路由不经过旧 _account 回调，所以登录后不会同步曲库。改版分支监听账号 ID 变化，先使旧同步代次失效、清理对应来源，再同步新账号；旧入口监听不变。回滚：关 redesign。正式装配门用真实路由与可控账号/目录验证。
