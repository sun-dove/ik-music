# ik 0.6.0 使用与构建

本版将独立产品显示名统一为小写 ik，桌面与开始菜单快捷方式使用用户提供的渐变音符图标。覆盖安装继续沿用原安装目录、包名、签名与数据目录；不需要卸载旧版本。

## 使用入口

首页提供继续播放、每日推荐、新歌和榜单。搜索一次查询本地、QQ、网易云和酷狗；各来源独立加载、重试和翻页。我的音乐区分平台收藏与本地收藏，提供歌单、本地音乐、下载和播放历史。我的集中账号、音源、音质、外观、听歌统计、智能歌单、备份、音效与悬浮歌词；标题下重复品牌副标题已经移除。

平台内容依赖服务可用性和账号权限。未登录、地区或能力限制、服务错误按实际返回显示；均衡器和桌面配套展示宿主能力，不能用开关状态冒充功能已生效。

Windows 窗口右侧在空间足够时展示队列；托盘支持显示窗口、播放暂停、上一首、下一首和退出。关闭窗口继续使用已保存偏好。再次启动唤醒现有窗口。窗口位置和大小恢复时限制在可用显示区域。系统媒体控制绑定当前播放状态。

Android 使用三 ABI 分包；Windows 使用安装器或完整解压 ZIP 后启动 yueyin_music.exe。ZIP 内的 DLL、data 与 ik.ico 必须一起保留。iOS/Linux 保留提供的图标适配资源，但没有对应发行包。

## 常用操作

- **睡眠定时**：进入“我的 → 音效与睡眠定时”，在“定时时长”选择 5～120 分钟，再打开“睡眠定时”。页面显示剩余时间，关闭开关即可取消；到点先淡出再暂停。剩余时间会定期保存，再次启动按已保存的剩余时间继续。
- **音效**：同页可开启“淡入淡出”并调节过渡时长；打开“均衡器”后选择预设或调节五个频段。以“均衡器设置已应用”为生效反馈；失败时点“重试”，不支持的播放后端会显示原因并禁用相关操作。
- **Windows 托盘**：点击通知区域的 ik 图标可恢复窗口，右键打开“显示 ik”、播放/暂停、上一首、下一首及“退出 ik”。没有歌曲时播放控制不可用。“我的 → 关闭主窗口时”可选择“最小化并继续播放”或“退出应用”；最小化后也可从任务栏恢复。
- **桌面歌词**：进入“我的 → 桌面歌词”开启；Android 需要允许悬浮窗权限，返回应用后可再次开启。未成功时页面显示失败提示和“重试桌面歌词”。可调整字号、文字与高亮颜色、描边和阴影，也可锁定窗口位置。无歌词歌曲显示占位文字。
- **备份与恢复**：进入“我的 → 备份与恢复”，点“导出为 JSON 文件”。文件名为 `ik-backup-日期时间.json`，导出完成后页面显示可复制的完整路径。Windows 保存到系统“文档”目录（可能已重定向到 OneDrive），Android 保存到应用文档目录，以页面路径为准。选择“从 JSON 文件导入”后先核对内容摘要，再确认合并；同名歌单合并去重，备份中存在的设置会覆盖本机对应项。导入前会在同一目录保留 `ik-before-import-…json` 恢复点；创建失败时不会开始导入。导入异常按页面提示检查自动恢复结果，并保留提示中的恢复文件。导入时睡眠计时会暂时停止，成功后按导入值恢复；其余设置按提示重新启动应用后全部生效。

备份包含歌曲信息、本地收藏、自建歌单、智能歌单规则、听歌统计明细及设置。平台登录凭据和单独保存的音源令牌不随备份迁移，新设备需要重新登录或填写令牌。音乐文件、下载缓存、背景图片和导入字体文件本体也不在 JSON 中；跨设备使用时需另行复制，并重新选择不可用的文件路径。

## 构建

独立版本以根目录 ik-version.json 为唯一输入。运行 scripts/sync_ik_version.ps1 生成 Dart、Windows 资源及 Inno 版本文件；加 -Check 可在 CI 验证。Android Gradle、独立构建脚本直接读取同一清单。原 Mconnect 入口与 pubspec 版本保持。

发行前运行 flutter analyze --no-pub 和 flutter test --no-pub -j 1。Windows 另跑既有音源宿主门、关闭策略红绿门与 ik 桌面原生红绿门。Android 用 scripts/build_video_apk.ps1 和既有稳定签名配置，Windows 用 scripts/build_video_windows.ps1。凭据配置不得提交。
