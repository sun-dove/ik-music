# IK Music 0.6.0 使用与构建

**版本：IK Music 0.6.0 / build 11。** Windows和Android最终安装包均已构建并通过本轮验收，下载入口为[0.6.0发行页](https://github.com/sun-dove/ik-music/releases/tag/ik-v0.6.0)。历史0.5.0安装包不含本版新界面。

最终Android三ABI包已完成签名、版本、ABI、许可和专用模拟器检查；Windows安装器及完整ZIP已构建，本机实际迁移到`D:\Applications\ik-music`，68个安装文件与清单一致，启动前14个用户数据文件完全保持。本文件是发行附加的最新版说明；安装包内说明保留构建时快照，最新设备和发布结果以本附件为准。

独立产品显示名统一为 **IK Music**，桌面与开始菜单快捷方式使用用户提供的渐变音符图标。包名、稳定签名、Windows安装身份、内部EXE和用户数据目录保持。Windows新安装默认目录为 `%LOCALAPPDATA%\Programs\ik-music`，本机迁移目标为 `D:\Applications\ik-music`；已有安装的迁移与旧目录清理按安装验收执行，不能将“保留用户数据”理解成“程序目录永远不变”。

## 使用入口

主界面分为 **发现、搜索、音乐库、最近播放、设置** 五区。发现提供继续播放、推荐、新歌和榜单；搜索一次查询本地、QQ、网易云和酷狗，各来源独立加载、重试和翻页。音乐库区分平台收藏与本地收藏，并保留自建歌单、导入导出、本地扫描、下载、离线缓存和智能规则入口。最近播放读取保存的收听历史，听歌统计另有入口。

设置分为 **播放与音效、外观、桌面歌词、音源、下载与缓存、账号、备份与恢复** 七区。常用选项行内修改；外观中的字体和图片先预览后应用。底部播放栏显示当前曲目，点击曲目打开完整播放器；推荐、新歌、榜单、专辑、歌手和歌单详情继续可达。

平台内容依赖服务可用性和账号权限。未登录、地区或能力限制、服务错误按实际返回显示；均衡器和桌面配套展示宿主能力，不能用开关状态冒充功能已生效。

播放队列由底栏队列按钮按需打开和关闭。Windows托盘支持显示窗口、播放暂停、上一首、下一首和退出；关闭窗口继续使用已保存偏好，再次启动唤醒现有窗口。窗口位置和大小恢复时限制在可用显示区域，系统媒体控制绑定当前播放状态。

Android 使用三 ABI 分包；Windows 使用安装器或完整解压 ZIP 后启动 yueyin_music.exe。ZIP 内的 DLL、data 与 ik.ico 必须一起保留。iOS/Linux 保留提供的图标适配资源，但没有对应发行包。

## 常用操作

- **睡眠定时**：进入“设置 → 播放与音效”，在“定时时长”选择15、30、45、60、90或120分钟，再打开“睡眠定时”；旧设置中的有效时长会保留为选项。页面显示剩余时间，关闭开关即可取消；到点先淡出再暂停。剩余时间定期保存，再次启动按保存值继续。
- **淡入淡出与均衡器**：在“播放与音效”开启淡入淡出并调节过渡时长；打开均衡器后选择预设或调节五个频段。设置写失败保持原值并显示行内错误；原生应用失败可重试，不支持的播放后端显示原因并禁用相关操作。
- **音量与静音**：使用底栏音量滑杆或扬声器按钮。用户音量与淡入淡出独立计算，淡入结束、切歌和播放器重建后继续使用当前音量；静音不会被播放恢复机制取消。调整失败会保留已确认值并提示重试，关闭静音恢复上次非零音量。当前值仅保存在本次应用会话，退出后回到默认100%。
- **3D 环绕**：同页可开启基于实测KEMAR HRTF的耳机空间处理并调整强度。开启后可能先显示等待音频处理，只有原生处理帧反馈匹配当前请求才显示实际生效；失败会请求恢复最后有效配置。Windows和Android使用共享FIR核心，设备与最终包验证范围见下文。
- **Windows 托盘与关闭**：点击通知区域的IK Music图标恢复窗口，右键可显示窗口、播放/暂停、切歌或退出。没有歌曲时播放控制不可用。“设置 → 外观 → 关闭主窗口后”可选择继续播放或退出应用；最小化后也可从任务栏恢复。
- **桌面歌词**：在“设置 → 桌面歌词”、底部播放栏或完整播放器使用共享的“词”开关。Android需要悬浮窗权限，拒绝时提示原因，授权后可重试；不支持的平台禁用开关。原生窗口成功后才保存状态，失败不会显示假开启，手动关闭歌词窗口也会同步按钮。设置提供字号、正文/高亮颜色和位置锁定；无歌词歌曲显示占位文字。Windows未接入的描边、阴影和鼠标穿透不作为可用控件展示。
- **备份与恢复**：进入“设置 → 备份与恢复”，点“导出 JSON”。文件名为 `ik-backup-日期时间.json`，完成后显示可复制的完整路径。Windows保存到系统“文档”目录（可能重定向到OneDrive），Android保存到应用文档目录，以页面路径为准。点击“选择备份”后先核对摘要，再“确认合并”；同名歌单合并去重，备份中存在的设置覆盖本机对应项。导入前在同一目录保留 `ik-before-import-…json` 恢复点；创建失败不会开始导入。导入异常按提示检查自动恢复结果并保留恢复文件。导入时睡眠计时暂时停止，成功后按导入值恢复；其余设置按提示重启后全部生效。

## 内置音源与高级管理

首次启动在首帧后自动准备固定20项目录，不需要手动输入URL。进入“设置 → 音源”可看到每项正在获取、受限初始化、等待安全生效、本机已准备或失败/限制原因；离线不阻塞启动，已保存脚本保留。获取先核对精确字节数和SHA-256，再严格解码和初始化。安装包只带目录、版本、哈希与许可证据，不带第三方脚本正文。

全新配置默认官方优先、自动尝试已启用候选、第三方下载关闭；升级用户的首选、排序、启用、音质和HTTP配置保留。准备成功不擅自改为音源优先，已有策略不适用时页面提供明确的启用操作。禁止批量下载的来源不会被自动开放下载。

播放期间准备完成后显示“等待安全生效”，在下一次明确播放或重启时批量发布；不会逐项暂停当前音乐。源管理页编辑期间后台不会覆盖草稿。你已停用或删除的项目不会被重试、更新恢复；恢复必须点对应项目的恢复操作。更新只使用应用发布的固定清单，不追随上游 `main/latest.js`；有上一已确认版本时可单项回滚。

“管理顺序、开关与自定义音源”继续提供HTTPS链接导入、更新、首选、排序、检查、下载许可与删除。手动新导入项目默认关闭；筛选只改变显示，保存或放弃由用户选择。最高可用模式按候选能力尝试并显示降档；请求音质与实际媒体格式/码率分别显示，未知字段保持未知。

目录完整显示、自动准备完成和歌曲成功播放是三个不同结果。Android脚本宿主需要Android 8.0以上及支持隔离运行的Android System WebView；系统版本满足并不保证旧WebView具备能力。显示失败时展开项目查看本机原因，网络恢复后可单项重试；限制项不会被计入可用数。Windows与Android的宿主及网络不同，某平台准备成功不会让另一平台显示成功。

## 备份与统计范围

备份包含歌曲信息、本地收藏、自建歌单、智能歌单规则、听歌统计明细及设置。平台登录凭据和单独保存的音源令牌不随备份迁移，新设备需要重新登录或填写令牌。音乐文件、下载缓存、背景图片和导入字体文件本体也不在 JSON 中；跨设备使用时需另行复制，并重新选择不可用的文件路径。

智能歌单已保存的生成结果快照对象不在备份 JSON 内，可在目标设备按规则重新生成。按歌手或专辑 ID 的高级规则依赖曲目本身提供的标识；新收藏和历史会保留这些字段，旧记录缺失的标识不会自动补全。听歌统计页展示常听前 100 首，超过时显示总数和展示范围，完整明细仍参与汇总和备份。当前界面语言为中文。

## 构建

独立版本以根目录 ik-version.json 为唯一输入。运行 scripts/sync_ik_version.ps1 生成 Dart、Windows 资源及 Inno 版本文件；加 -Check 可在 CI 验证。Android Gradle、独立构建脚本直接读取同一清单。原 Mconnect 入口与 pubspec 版本保持。

发行前运行 `flutter analyze --no-pub` 和 `flutter test --no-pub -j 1`。Windows另跑音源宿主门、新自动目录设备门、关闭策略与IK桌面原生红绿门，以及HRTF处理帧和信号门。Android用 `scripts/build_video_apk.ps1` 和既有稳定签名配置，始终生成arm64-v8a、armeabi-v7a、x86_64三ABI分包；Windows用 `scripts/build_video_windows.ps1`。3D原生依赖按独立构建脚本生成，运行时库、许可和HRTF署名必须随包保留；不添加另一套完整FFmpeg命令程序。凭据配置不得提交。

## 已验证范围与当前边界

七区设置在1440、1200、900、720、390、320宽度以及100%、125%、150%字号下，共126组合通过；真实20条音源目录纳入布局验证。混合质量、外部字体/质量更新、写失败回滚、歌词原生失败与关闭回传、并发设置写入均有正式场景门，见[工作区实施验收](../IK-Music-工作区实施验收.md)。

新自动目录的Windows设备门完整覆盖20项，当次14项真实获取、哈希、初始化并发布；非常道超时，常青、小草、聚合、六音按历史能力不自动运行，星海保留使用范围限制。结果会受网络和来源服务影响，详情见[U08 Windows设备记录](../IK-Music-U08Windows设备记录.md)。

最终安装版在用户本机首次后台准备15项并显示等待安全生效；正常退出并重新启动后，界面确认**15/20项本机已准备**，非常道这次成功。常青、小草、聚合、六音保持不支持，星海受限。未手动粘贴或导入链接；这次结果与上述早先设备门时间不同，不能相加或据此承诺每首歌曲可播放。

最终Android现包在专用API30 x86_64模拟器进入“设置 → 音源”，未贴链接或点手动重试，已自动显示全部20项目录并运行准备流程。连续6页UI语义与截图逐项核对，无遗漏，汇总明确为“本机已准备0/20项”：

3D共享C核心的296项方向/采样率信号门已在WSL与Android API30 x86_64模拟器通过；Windows真实libmpv的12组方向/EQ处理输出和帧反馈、18组格式/传输/EQ/1.25倍速组合已通过。Android专用release门经过真实just_audio → Media3 → JNI处理52,800帧：前4096帧右输入声能为0、右输出为0.703786939，证实双耳卷积；强度/方向调整、seek、停止重载与关闭通过。专用门APK不等于产品发行包，最终产品启动另验。HRTF是通用KEMAR耳机双耳处理，不包含头部追踪或Atmos对象解码；ARM物理设备听感、蓝牙延迟与持续功耗待验，见[3D音效实施记录](../IK-Music-3D音效实施记录.md)。
