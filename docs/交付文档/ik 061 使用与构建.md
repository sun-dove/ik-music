# IK Music 0.6.1 使用与构建

**版本：IK Music 0.6.1 / build 12，待发布。** 本文介绍此版本已实现的界面与操作方式。0.6.1尚未公开，当前正式下载仍为0.6.0/build11；安装包与更新记录以[GitHub发行页](https://github.com/sun-dove/ik-music/releases)为准，源码与详细验收范围见[项目仓库](https://github.com/sun-dove/ik-music)。

产品在桌面、Android和应用内统一显示 **IK Music**，使用用户提供的渐变音符图标。GitHub仓库为`sun-dove/ik-music`。Android包名和稳定签名、Windows安装身份、内部EXE及用户数据目录保持。Windows新安装默认目录为`%LOCALAPPDATA%\Programs\ik-music`；本机已有目录为`D:\Applications\ik-music`，普通更新沿用已登记目录。

## 主界面与找歌

主界面分为 **发现、搜索、音乐库、最近播放、设置** 五区，底部播放栏始终保留。顶部显示当前位置，右侧共用搜索框输入歌曲、歌手或专辑后按Enter执行查询；窄窗自动换行。切换主区保留已打开页面状态和输入内容。

发现页提供新歌、榜单、继续播放和推荐。推荐卡片显示真实歌曲封面、歌名和歌手，每平台精选展示最多6首并提示范围；“浏览全部”进入完整推荐。点卡片从该首开始播放时沿用该来源已获取的完整列表；更多按钮保留原操作。推荐出处、榜单回退说明、加载、错误、重试和登录分别显示，不使用设计稿里的虚构歌单。

搜索一次查询本地、QQ、网易云和酷狗，各来源独立加载、重试和翻页；音乐库区分平台收藏与本地收藏，保留自建歌单、导入导出、本地扫描、下载、离线缓存和智能规则入口。最近播放读取原始收听历史，听歌统计另有入口。窄窗收起非关键列表列，歌曲和主要操作仍可达。

音乐库中的“喜欢的音乐、我的歌单、本地音乐、下载、智能歌单”在同一外壳内切换。从歌单或规则详情返回会回到原分类；已访问分类保留筛选和页面状态。本地歌曲使用共用歌曲列及更多按钮，专辑、歌手、文件夹分组和多选添加歌单继续使用原数据。窄窗分类可横向滚动，多选操作分行显示。

新歌、榜单与完整推荐页面在顶部切换网易云、QQ音乐和酷狗，仅展示当前平台；新歌地区、失败重试及不支持说明仍按平台保留。QQ热歌榜在QQ标签内。推荐来源会明确显示：对应平台登录且接口确认的个人内容才能称为网易每日推荐或QQ今日私享；榜单回退、首页回退及匿名或无法确认的来源分别显示榜单推荐、首页推荐或平台推荐。

搜索尚未输入时展示现有QQ热词接口与各平台当前推荐精选，点热词执行原搜索，“查看全部推荐”进入完整推荐页。热词获取失败显示实际原因和重试，手动输入不受影响。本次接口核查中QQ热词返回HTTP500，所以该服务恢复前会显示失败状态；不使用写死词条冒充实时热门。

平台内容依赖服务可用性与账号权限。未登录、地区或能力限制、服务错误按真实返回显示。音源准备成功不代表所有歌曲或音质都可用。

## 播放详情

点击底栏当前歌曲打开完整播放器。宽窗显示左封面及歌曲信息、右歌词；长歌名最多两行。具有真实歌手或专辑标识时显示相应入口，缺少标识时只显示名称，不按同名猜测跳转。

音源信息位于封面下，显示曲目所属平台、当前来源和格式/码率，点箭头直接展开尝试详情；格式或码率没有确认时保持“尚未确认”。失败原因、未试音源和继续尝试根据真实播放状态出现。窄窗歌曲与来源区可独立滚动，歌词和播放控制保持可用。

歌词支持自动跟随、手动浏览和回到当前句；页内可调整字号及译文显示。点击可定位的歌词回到对应时间并恢复跟随；切歌中或缺少有效时间时不能定位。歌词为空、没有时间信息和加载失败分别显示实际状态。本轮没有增加Windows桌面歌词鼠标穿透或独立歌词字体能力。

播放队列仍由底栏按钮按需打开，表示接下来待播放的歌曲；最近播放记录已经听过的歌曲。两者用途独立，队列不常驻占用主界面。

## 设置与常用操作

设置分为 **播放与音效、外观、桌面歌词、音源、下载与缓存、账号、备份与恢复** 七区。常用选项行内修改；字体和背景先预览后应用，主题使用浅色、深色和跟随系统预览按钮。

当前新版歌曲的简单操作从按钮旁展开；歌单目标、导出格式、二维码、音质与账号操作使用居中窗口。智能歌单排序使用同一菜单样式。按Esc或点窗口外部关闭会保留原页面，取消不保存；规则排序仍需点原“保存”才写入。系统文件或目录选择器继续使用对应平台的原生能力。

- **睡眠定时**：在“播放与音效”选择15、30、45、60、90或120分钟并打开开关。旧设置中的有效时长会保留；到点先淡出再暂停，剩余时间按原机制保存和恢复。
- **淡入淡出与均衡器**：同页开启并调节。五频均衡器在宽度允许时并排竖向显示，窄窗保持可操作。写入失败保持原值并显示行内错误；原生应用失败可重试，不支持的后端显示原因并禁用相关操作。
- **3D环绕**：独立强调卡提供基于KEMAR HRTF的耳机空间处理和强度调节。开启后可能等待音频处理，收到对应处理帧后才显示实际生效；请根据状态文字判断。使用现有Windows/Android音频处理链。
- **音量与静音**：使用底栏滑杆或扬声器按钮。用户音量与淡入淡出相乘，切歌和播放器重建保留本次会话值；静音不会被恢复机制取消。调整失败保留已确认值并提示，取消静音恢复上次非零音量；退出后当前音量仍回到默认100%。
- **托盘与关闭**：Windows通知区域图标可恢复窗口；右键提供播放暂停、切歌和退出。“外观 → 关闭主窗口后”继续使用已保存偏好，可选继续播放或退出。再次启动唤醒已有窗口。
- **桌面歌词**：设置页、底栏与完整播放器共用一个开启流程。Android需要悬浮窗权限；原生窗口成功后才保存开启状态，失败显示原因，手动关窗同步按钮。字号、正文/高亮颜色与位置锁定继续可用；不支持的平台显示能力限制。

## 个人每日推荐

发现页的「每日推荐」进入独立个人页面，切换网易云、QQ音乐或酷狗后只显示当前平台结果。需要对应平台的有效音乐会话；未登录、身份信息不完整、会话过期或需要平台验证时，按页面提示连接账号或自行完成验证。账号和凭据改变后旧个人曲目立即清除。

网易云与酷狗读取个人推荐，QQ只读取明确的「今日私享」卡片及其完整歌单分页。客户端按平台顺序完整解析去重，最多展示30首；少于30首显示实际数量，不用公开榜单补齐。「播放全部」只播放本页展示的曲目。成功后可以刷新；加载中清旧列表并禁重复刷新和播放。网络、服务、响应错误与空结果分别提示，重试只作用当前平台。

平台更新日期未获确证时只显示获取日期。酷狗新接口的时长单位尚待真实响应确认，暂不猜测填入。当前协议、状态与界面动作已用虚构会话和HTTP替身验收，真实三平台账号能否成功返回个人歌曲仍需实际核实。

## 下载管理与目录

音乐库和设置的下载入口进入同一下载工作区，按 **进行中、已完成、失败** 切换。进行中任务可暂停或继续，失败任务可重试；批量动作只作用当前允许操作的手动下载任务。离线缓存仍由原入口管理，不混进手动下载列表。

任务详情显示真实状态、大小/进度、失败原因与已知路径。完成任务可请求打开所在目录：Windows使用系统目录打开能力，Android的SAF路径使用已保存目录授权；缺路径、授权或系统服务失败时显示原因。对应真实设备目录打开仍列入最终成品验收，不能以接口门代替系统操作。

再次下载同一曲目及音质时，反馈区分“新增”“已存在”“已请求重试”和“失败”。提示只表示入队结果；下载完成以任务最终状态为准。播放音质与下载音质分别保存，改变下载音质不会暂停当前播放。

## 内置音源与高级管理

首次启动在首帧后自动准备固定20项目录，不需要逐项输入URL。设置中的音源页完整显示获取、受限初始化、等待安全生效、本机已准备和失败/限制原因；离线不阻塞启动，已保存脚本保留。获取先校验精确字节与SHA-256，再严格解码和初始化。包内只带目录、版本、哈希及许可证据，第三方脚本正文不随包分发。

全新配置默认官方优先、自动尝试已启用候选、第三方下载关闭；升级用户的首选、排序、启用、音质和HTTP配置保持。准备成功不擅自改变策略，也不自动开放受限来源下载。播放期间准备完成的项目等待下一次明确播放或重启生效；后台不会覆盖管理页草稿。

已停用或删除的项目不会被重试、更新恢复，恢复需明确操作。更新使用应用发布的固定清单，不追随上游浮动链接；有已确认历史版本时可单项回滚。高级管理继续支持HTTPS导入、更新、首选、排序、逐项检查、启停和删除。

Android脚本宿主需要Android8.0以上及具备隔离运行能力的Android System WebView。系统版本满足不代表旧WebView具备能力；失败时展开查看本机原因。Windows与Android宿主及网络状态独立，不互相借用成功结论。

## 备份与统计范围

“备份与恢复 → 导出JSON”生成`ik-backup-日期时间.json`并显示路径。Windows保存到系统文档目录，Android保存到应用文档目录，以页面实际路径为准。“选择备份”先核对摘要再确认合并；导入前保存`ik-before-import-…json`恢复点，创建失败不开始导入。失败时按提示检查恢复结果并保留恢复文件。

备份包含曲目信息、本地收藏、自建歌单、智能歌单规则、听歌统计明细与设置。同名歌单按原逻辑合并，备份中设置覆盖对应项；账号凭据、音源令牌、音乐文件、下载缓存、字体与背景文件本体不随JSON迁移。智能歌单生成结果快照不包含，可按规则重新生成。旧曲目缺少的歌手/专辑标识不能凭空恢复；统计页展示常听前100首并提示实际范围，完整明细仍参与汇总与备份。
