## 已知边界

- juhe 的主机诊断遇到服务端 HTTP 429 后等待；Windows 的最终阶段另见表中结果，不能承诺换接口即可成功。
- sixyin 使用 HTTP 初始化请求，当前受控桥只允许 HTTPS；初始化请求被拒绝后脚本还会继续访问空值。本版明确说明原因，不开放不受控网络。
- grass 仅有酷我能力，不能因初始化成功便提示可用于 QQ/网易云/酷狗。
- 主机与 Windows 使用不同环境声明和真实引擎，结果不同必须分别保留。
- Android 当前没有连接设备，全部20源在 Android 本机引擎的初始化和真实歌曲解析、媒体加载、完整播放、音频实际质量均未测。Windows 本轮也没有进行第三方源的真实歌曲播放。
- 酷狗另做真实匿名搜索，返回3首公开元数据、平台总数480。扫码登录、本人全部收藏、歌单和官方/第三方完整播放尚待本人账号与设备验证。
