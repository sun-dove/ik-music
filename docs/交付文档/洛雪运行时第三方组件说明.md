组件及完整许可包含在Flutter assets和源码包中，并加入独立入口的LicenseRegistry。应用运行时不从CDN下载这些组件，不暴露Node、文件系统或平台账号凭据。Android与主机诊断使用Dart Random.secure提供的64 KiB随机池；Windows浏览器环境的只读crypto对象使用WebView2安全随机接口，仍遵守浏览器单次调用限额。缓冲区和解压输出限制为512 KiB。

正式回归用Node作为受信任计算代码的对照运行器，验证27项断言：MD5、二进制与UTF-8、ArrayBuffer视图、AES各密钥长度及CBC/ECB/CTR/CFB/OFB、RSA无填充约定、随机长度、压缩往返与超限、无宿主系统接口。Node不执行第三方音源。第三方音源仅在专用隔离引擎中执行：Android系统JavaScript沙箱、主机诊断的QuickJS WASM、Windows独立受限WebView2宿主；实际平台结果分别记录。Windows SDK及其许可另见《悦音音乐040Windows说明》。

这是洛雪常用接口的兼容实现，不等于完整 Node Buffer/crypto 或浏览器 DOM。没有实现的接口仍明确失败；平台限制、源服务失效和具体歌曲能否取得音频必须另验。
