# 悦音音乐：音源管理、酷狗、浅色图标与 Windows 版设计

日期：2026-11-16。状态：用户已确认试行；用户追加要求继续适配此前提供的音源仓库。2026-11-16 选定奶白底音符与波浪图标，随后回复“可以试试看，然后之前给你发的音源的你再多适配一下”。按本文既定场景先红门，再实现；真实平台/设备结果独立记录。

## 背景与目标

用户希望优化音源列表，加入酷狗音乐，换成浅色且美观的图标，提供 Windows 版本，并继续开源。

本轮以已公开的 yueyin-music 工作副本为后续开发主线，保留原 video-music 工作目录。远端 main 当前仍为 635edbfc2d0f54a5d946a43a8dec1180682a19b4。已有 Android 0.3.3 的账号、收藏、音源与播放偏好需要兼容升级；不能改变原 Mconnect 默认入口的公开契约。

目标交付为一套共用业务逻辑、分别适配手机与电脑的悦音音乐；Android 继续三 ABI 分包，Windows 首先支持 x64，提供完整便携 ZIP 与安装包。源码和可公开的构建说明继续同步原 GitHub 仓库。

## 方案比较

| 方案 | 做法 | 优点 | 代价与限制 |
| --- | --- | --- | --- |
| A：界面小改，Windows 先只做官方播放 | 整理旧音源页面、增加酷狗入口，复用 Windows 默认运行器；电脑暂不运行 LX 脚本 | 改动较少，较快验证基础搜索和播放 | 手机与电脑能力不同，用户关心的自定义音源无法在电脑使用；必须显式禁用并说明 |
| B：共用业务、独立适配手机与电脑 | 新音源管理视图；完整接入酷狗；新增 Windows 沙箱与宽屏外壳；统一品牌和发行配置 | 手机、电脑都有清楚的音源管理与播放链路，可持续开源维护 | 增加原生运行时、包装和跨端验收；不能跳过 Windows 音源技术门 |

## 音源列表：先明确用户看到什么

1. 页首显示总数、启用数和导入按钮。播放策略放在可展开区域，三个开关仍为独立设置；老用户不被自动改成推荐设置。
2. 每条音源默认显示名称、版本、首选标记、启用开关、支持的平台标签和一行检查结果。平台标签将 kg 显示为“酷狗音乐”；音质展开后显示，避免长文本把整页撑满。
3. 更新、检查脚本、允许下载、删除放在详情/更多菜单。允许下载仍需显式开启，不能因换页面而默认允许。
4. 默认按用户手动顺序展示。拖动和上移/下移互为替代，支持触摸、鼠标与键盘；首选在播放时优先，显示其实际优先级。筛选/搜索只影响显示，不改底层播放顺序；筛选时禁用拖动并说明原因，清除筛选后可排序。
5. 提供名称查找、全部/已启用及平台筛选。搜不到显示“没有匹配的音源”，仍能清除筛选和导入。
6. 保存操作始终可见；有修改时明确“有未保存的更改”，保存成功才显示“已保存”。返回时可保存或放弃；写入失败保留草稿，不能显示成功。
7. 导入、更新、检查过程中显示操作对象与取消入口；失败只影响该条记录，旧版脚本、开关和顺序继续保留。相同标准化链接更新原条目，同名不同链接可以并存。
8. “已导入”“初始化通过”“最近一次歌曲播放成功”分别标记。初始化不是速度测试，也不能叫作“全曲库可用”。状态带检查时间，脚本更新后旧状态失效；歌曲播放成功必须绑定歌曲、档位、脚本哈希和运行平台。
9. 批量检查按当前完整筛选结果逐项执行，显示已完成/总数并可取消；未执行项显示“未检查”。慢源、失败源和取消不会被默默当作成功，也不静默只测前 N 个。
10. HTTP 自定义源设置仍可进入，维持其与 LX 模式切换的原规则，不在本次擅自合并两套存储协议。

## 酷狗场景

- 手机底部导航增加“酷狗”；搜索平台选择、收藏页、“我的”账号区、播放/下载音质设置同步增加酷狗。电脑版同样显示该平台。
- 支持匿名搜索、扫码登录（区分酷狗音乐与概念版）、用户歌单及喜欢、播放、歌词、已授权资源下载；优先利用既有接口，明确服务端拒绝、暂不支持或返回不完整的情况。无需新增手机号登录或本次新造平台推荐功能。
- 会话恢复、登出、过期提示和迟到请求保护按平台隔离。酷狗失败不清除 QQ/网易云账号；未登录不是“收藏为空”，分页失败不是“已同步全部”。
- 追加独立酷狗目录适配器，保留歌曲 hash、album_audio_id、可核实的各档 hash 与音频标识。来源不明的字段保持未知；搜索记录、收藏记录缺字段时补详情，不伪造高音质 hash。
- 新版本 LX 平台描述支持 kg，向音源传符合其公开协议的酷狗 musicInfo。确认样本契约后再实现，不把 QQ 的 songmid 当成酷狗 hash。脚本只声明 tx/wy 时，对酷狗明确显示“不支持此平台”，不执行无效候选。
- 同一首酷狗歌曲继续按已经确认的“同档尝试各源，再逐档降低”策略播放。VIP 歌曲能否播放由官方权限或所选源实际资源决定，不承诺启用音源就一定能播放。

## Windows 版

### 界面与安装

- 首版目标为 Windows x64，优先 Windows 10/11。具体最低系统版本取决于选定并验证的运行时版本，发布前固定并写入说明。
- 宽窗口使用左侧导航、中央列表和底部播放器；窄窗口回退紧凑布局。音源详情可用侧栏，歌曲播放、歌词、队列与账号逻辑复用。
- 应用名、窗口标题、任务栏图标、EXE 元数据和安装器统一为悦音音乐，独立 yueyin_music.exe；安装 AppId 与数据目录与 Mconnect 分离。
- 交付便携 ZIP 时包含 EXE、DLL 和 data 等完整运行目录；“便携”仅指免安装解压运行，首版用户设置仍放系统应用数据目录，不承诺写回 EXE 同级文件夹。
- 安装器支持用户选择位置（包括 D:/Applications），不静默拉起大体积工具链。缺少 VC++/WebView2 时显示可操作的安装说明，不能闪退或把缺运行时显示成“音源失效”。
- Android 原包名和稳定签名保留，新构建号递增；Android 账号和本地音源不需要手动重建。Windows 与安卓不自动同步凭据和脚本，本次不增加云同步。

### 自定义脚本的技术门

拟增加实现现有 LxSandbox 接口的 Windows 适配器，优先验证以 WebView2 隔离的 JavaScript 上下文和单独受限宿主进程为方案。已有 WebView2 安装仅表示运行时存在，不代表桥接、隔离或本工程构建已经通过。

要求：专用非账号浏览配置；禁用宿主对象、导航、弹窗、外部内容与直接网络访问；脚本只通过受控消息队列向 Dart 请求网络；不暴露文件、进程、Node、账号 Cookie 或任意宿主调用。验证 worker/iframe、fetch/XHR/WebSocket、资源加载等旁路；进程有时间/内存上限，主进程可强制结束死循环和清理会话。已有 lx_http 的地址、重定向和大小限制继续由宿主执行。

实现前做最小原生验证门：创建/执行/销毁、JSON 返回、异步回调、死循环可终止、网络旁路被阻止、切歌/取消不回传旧结果。测试不通过时，Windows LX 功能不得标为完成；补充替代运行时方案和许可再讨论，不临时换成不受限的 Node 执行。安卓继续使用原隔离实现。
