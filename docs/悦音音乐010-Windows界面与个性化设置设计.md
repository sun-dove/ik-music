## 问题背景与目标

用户的三张 Windows 截图对应三个真实问题：设置页把三平台音质重复列出；播放页只显示一行歌词，宽屏空间没有利用起来；关闭窗口的“是/否”弹框难以理解。用户同时要求更换背景和字体、使用平台真实图标，并希望选用苹方。

推荐最终界面：

1. “我的”页只出现“播放音质”“下载音质”两行，各平台使用统一选择，二者独立设置。
2. 个性化设置集中显示主题、背景和字体，修改后可预览，取消保留原设置。
3. QQ 音乐、网易云音乐、酷狗音乐使用已核实厂商来源的真实图标；已登录账号继续显示用户头像。
4. Windows 默认正文使用微软雅黑 UI，适当增加字间空间和字号，标题以中等字重为主。字体可选择本机已安装的字体，包含安装后的苹方 SC；支持导入有使用权的 TTF/OTF 文件。
5. 宽屏播放页左侧显示封面、歌名、歌手，右侧持续显示完整歌词，当前句高亮。底部保留播放、进度、队列、音质和实际播放来源。
6. 设置提供“关闭主窗口时：最小化并继续播放 / 退出应用”。推荐默认最小化并继续播放，应用仍可从任务栏恢复；设置中另有“退出应用”入口。

## 两个方案比较

| 方案 | 做法 | 优点 | 代价与兼容风险 |
| --- | --- | --- | --- |
| A：直接修改现有页面和设置 | 合并三个平台的写入，修改共享主题与播放器，在原 Win32Window 中加入关闭分支 | 文件少，能快速看到变化 | 易覆盖历史各平台音质；Android 与默认 Mconnect 页面可能随之变化；原公开路径的变化较多 |
| B：新增 Windows 配置与桌面组件，按入口选择 | 独立保存统一音质、背景与字体；新增桌面设置和播放页；Windows 主入口选择新组件，原公开接口保持 | 旧设置可回退；平台能力与音源策略复用；新增能力可独立验收和停用 | 需要少量装配点及原生窗口/字体通道，必须对这些接入点做回归 |

推荐 B。统一设置是 Windows 的展示与偏好层，歌曲、平台、账号和音源仍沿用现有服务。必须接入的生产路径、全部已知调用方和回滚方案列在同目录《悦音音乐010-Windows改版接入票据》中；用户确认设计时一并确认这些最小接入改动。

## 体验先定义

### 两项音质

- 播放提供“优先最高可用”和现有固定档位。最高可用沿用 0.4.0 的源候选及明确降档提示；本轮不另行扩展音源能力或更换资源解析算法。
- 下载提供统一的“标准 / 高品质 / 无损 / Hi-Res / 母带（平台支持时）”固定档位，映射既有 `AudioLevel`。本轮合并下载入口，不新增下载自动降档，避免把低档文件标成用户选择的高档。
- 不把三个平台的商业档位名称视为完全相同的编码或权限。选择器使用通用名称，显示“实际可用档位取决于歌曲、平台与音源”；播放器继续显示实际返回的来源、格式、音质和降档情况。
- 升级时保留原 `video.<platform>.play/download` 键。尚未选择统一音质时，实际调用仍按各平台原值；原值一致则显示通用档位，不一致则该行显示“沿用原设置”。点击并保存统一档位后对三平台生效，旧键保留。
- 播放最高可用继续以既有 `SourceCollection.highestQuality` 为模式来源。统一固定档位与该模式联合保存；失败恢复旧快照并明确提示，不能出现界面显示新设置、播放器仍使用旧设置的情况。
- 播放设置改变时，仅对当前在线歌曲重新请求音质；本地歌曲继续原控制行为。正在下载的任务沿用提交时的档位，新任务和用户明确重试的任务使用新选择。
- 设置页、播放页的音质按钮、批量下载、下载重试和离线缓存入口必须读取同一“有效音质”，不得留下一处仍绕过统一设置。

### 背景与字体

- 背景支持默认背景、本机选择 PNG/JPEG/WebP、恢复默认。图片确认后复制到悦音自己的应用数据目录，移动原图片不影响显示。
- 选择器先预览图片及柔化程度；明确“应用”“取消”。已保存背景在首页、搜索、收藏、设置及宽屏播放页显示；覆盖层按深浅主题调整，卡片保持可读。
- 图片解码失败、文件不可访问、保存失败分别显示原因。失败保留当前背景；已保存图片后来丢失则回退默认背景，并在背景设置里显示恢复入口。
- 只有本机实际可用的字体才出现在可选列表。首次缺省使用微软雅黑 UI，并保留系统无衬线字体回退；字体安装/移除后可以刷新列表。
- 字体导入仅支持 TTF/OTF；TTC 字体可经 Windows 正常安装后从列表选择。导入先尝试加载，确认后保存到悦音独立目录。无法加载或无法保存时保留当前字体。
- 字体在页面、标题、弹窗和歌词中一致应用。用户原先选择的字体后来不可用时，回退默认字体并在设置提示，不阻止软件启动。
- 苹方不是 Windows 自带字体。系统和当前用户的字体注册表中均未找到 PingFang。Apple 系统字体目录可查到 PingFang SC；macOS Tahoe 许可第 2.E 节限制字体在运行 Apple 软件时的使用，并要求嵌入遵守对应字体限制。本轮没有取得 Windows 安装包分发授权，因此只支持用户合法安装/导入的字体，不附带苹果字体文件。

### 右侧滚动歌词

- 内容区域宽度至少 840 像素时，左右布局；缩窄或高缩放时使用纵向布局，完整歌词仍可滚动。最小窗口及 125%/150% 缩放都要覆盖。
- 时间轴沿用现有歌词、播放进度及 seek 回调。当前行按时间戳高亮，以实际布局位置滚动，不使用“行号乘固定高度”猜测多行歌词位置。
- 鼠标滚轮、拖动滚动条、键盘滚动后暂停自动跟随，显示“回到当前歌词”。点击该按钮恢复跟随；点击有时间戳的歌词定位播放。
- 切歌、拖动进度条、歌词迟到和播放暂停均保持高亮与滚动状态一致。纯文本歌词可滚动，但不显示虚假的逐句同步；没有时间戳的行不启用定位。
- 歌词加载中、没有歌词、加载失败分别显示既有中文状态。已有重试入口可继续使用；歌词区域不挤走底部播放控件和错误信息。

### 平台图标

- 已获取三个厂商应用条目的 512 像素原图，核对了应用 ID 与发布者，文件位于 `design/platform-icons-010`，完整来源和 SHA-256 见该目录《来源说明》。
- QQ 音乐应用 ID 为 414603431，网易云为 590338362，酷狗为 472208016。使用相应厂商发布的主应用图标。
- 用于侧栏平台入口、平台标识、未登录账号入口。显示尺寸统一，保留平台文字及无障碍标签；已登录用户头像不替换。
- 产品接入时注册本地资源，运行时不依赖官网或 App Store 下载图标；同步加入第三方来源声明。图标与商标归原权利人，代码开源许可不改变素材权利归属。

### 关闭窗口

- 主窗口右上角关闭按钮及 Alt+F4 遵循同一个设置。推荐缺省“最小化并继续播放”，不再显示含义倒置的“是/否”弹框。
- 这里的“最小化”保持任务栏入口，不标成系统托盘。本轮不新增托盘服务。
- 选择“退出应用”时，关闭主窗口真正退出应用；设置里的独立退出按钮同样真正退出，包括已选择最小化的情况。
- 原生通道未初始化或保存失败时，不假报“已应用”。无法使用的版本禁用相关选项并显示状态；未启用新增 Windows 装配的旧入口仍走既有逻辑。
- 系统关机/注销按系统结束会话处理，不改成最小化；重复关闭不重复创建处理器，不留下音源宿主或字体文件句柄。

## 接口与数据结构

以下为新增接口建议，保持旧公开接口的参数、返回类型和缺省行为。实现时不引入额外架构层。

| 新增项 | 数据或契约 | 边界 |
| --- | --- | --- |
| WindowsMusicPreferences | 独立可选配置键 `video.windows.appearance.v1`；`playQuality?`、`downloadQuality?`、`background?`、`font?`、`closeAction?` | 旧 VideoPreferences 及平台音质键不改；字段缺省回退原值，Windows 新关闭默认由明确装配启用 |
| 有效音质读取方法 | `quality(platform, download: false)`：有统一固定值则用它，否则委托原 preferences.quality；最高播放模式继续读 sourceSettings | PreparedSourceRouter 和下载调用的签名不变；统一设置只替换 Windows 注入的读取函数 |
| BackgroundSelection | `relativePath?`、`soften?`；默认无图 | 仅引用本应用目录内保存的图像，不向外部发送路径或图片 |
| FontSelection | `family?`、`relativePath?`；系统字体与导入字体二选一 | 导入文件仅在确认后保留；动态加载使用新模块，不修改已有字体资源 |
| DesktopAppearanceState | 草稿、保存状态、可恢复错误、应用后的配置 | 界面按结构化结果显示成功、不可用、读写失败，不靠字符串猜测按钮状态 |
| Windows 个性化主题扩展 | 字体族/回退、背景/遮罩、桌面表面透明度 | VideoTheme.light/dark 原入口保留；只有 Windows 新主题包含扩展 |
| WindowsMyPage / WindowsPlayerPage | 新桌面设置组件、新歌词布局；复用原账号/播放回调与数据 | VideoMyPage、VideoPlayerPage 原构造和默认行为保留 |
| WindowsWindowController | `setCloseAction(action)`、`exitApplication()`、`listFonts()`；字体列表带 family 与可选样式信息 | 新 MethodChannel，仅 YUEYIN_BUILD 注册；原 Win32Window 公共方法不改 |

关闭行为枚举为 `minimize`、`exit`；不存在新配置的旧入口不调用设置通道。配置错误至少区分 `invalidImage`、`invalidFont`、`fileMissing`、`readFailed`、`saveFailed`、`nativeUnavailable`，每类都有明确显示与可恢复操作。
